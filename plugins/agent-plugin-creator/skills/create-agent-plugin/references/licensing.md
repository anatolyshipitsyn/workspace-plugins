# Licensing

This package may use Apache-2.0 as its project license, but bundled upstream
materials keep their original attribution requirements.

Attribution rules for this plugin:

- Bundled Agent Plugins JSON schemas remain attributed under Apache-2.0.
- Copied specification prose or copied documentation examples must retain
  CC-BY-4.0 attribution.
- Prefer concise summaries and upstream links when that is enough; do not copy
  large specification sections unnecessarily.

Repository-specific expectations:

- Keep attribution notices inside the plugin package.
- Do not remove `plugins/agent-plugin-creator/specs/1.0.0/NOTICE.md`.
- Document the attribution policy in `README.md`.
- Avoid adding third-party text or assets without clear license provenance.
